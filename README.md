# 🏥 SmartQueue - Hospital Queue & Appointment Management System

SmartQueue is a modern Hospital Queue and Appointment Management System designed to reduce patient waiting time and improve hospital workflow through real-time queue tracking and appointment scheduling.

---

## 📌 Project Overview

SmartQueue digitizes the traditional hospital queue system by allowing patients to book appointments online, receive queue tokens, track their live queue position, and get estimated waiting times.

The system provides separate dashboards for Admin, Doctor, Receptionist, and Patient with role-based access.

### Clone Repository

